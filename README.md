# AWS-VPC-Notes-Hands-On-Project
AWS VPC Project with Public & Private Subnets, NAT Gateway & Secure EC2 Setup! 🔐🌐 (Notes Included For Certification)

Thrilled to share my latest hands-on AWS project, where I built a custom Virtual Private Cloud (VPC) architecture with secure and scalable networking components! 💡🔧

This setup mimics real-world cloud infrastructure, internet access control, and EC2 connectivity across zones.



💡 What I built:

 ✅ Custom VPC with CIDR 

 ✅ 2 Public Subnets & 2 Private Subnets across multiple AZ's

 ✅ Internet Gateway for public subnet access

 ✅ NAT Gateway for secure internet access from private subnets

 ✅ Separate Route Tables for public and private routing logic

 ✅ EC2 instance in public subnet for SSH Bastion and NAT jump-host

 ✅ EC2 instance in private subnet tested for outbound internet access via NAT

 

📦 Tech Stack: AWS VPC | EC2 | IGW | Route Tables | NACL | Subnetting | Security Groups | NAT Instance |
